# Купол (Cupola)

Офлайн Android-визуализатор вокальной тренировки: спектрограмма, нота и отклонение в центах, обертоны, «звон» (энергия в полосе певческой форманты ~2.4–3.6 кГц) относительно личной калибровки, очки за удержание звука «в куполе». Без облака, без телеметрии: аудио не покидает устройство.

**Это не медицинский инструмент и не замена преподавателю.** Приложение показывает, что произошло со звуком, и не даёт технических вокальных инструкций. Если горло устало или болит — прекратить занятие независимо от очков.

Документы: `SPEC.md` (спецификация, §15 — границы и визуал v0.1), `RESEARCH.md` (научная база), `TICKETS.md` (план работ и статусы), `design/mock-analysis-v0.1.html` (макет экрана «Анализ»), `docs/device-notes.md` (что проверено на стенде), `CHANGELOG.md`.

## Что умеет 0.1.0

- Экран «Анализ»: нота (RU/EN) и центы, шкала ±50 ¢, обертоны, вибрато/качание/тремоло, дуга «купола» относительно калибровки; спектрограмма 8 с (лог/лин шкала, лента купола, трек высоты, линия закреплённой цели, тики гармоник); спектр с огибающей и номерами гармоник. Портрет и ландшафт, светлая и тёмная темы, русский и английский.
- Сессия («Старт»): очки за звук в куполе, серии, подсказки «Громче ≠ звонче», «Нота плывёт», «В позиции», сводка; продолжается в фоне (уведомление); вибрация по баллу (на телефонах включена по умолчанию).
- Пауза с прокруткой 60‑секундного буфера спектрограммы.
- Калибровка (2 с тишины + 4 с «а») по типу голоса или своему диапазону купола; настройки с пояснениями «?».

## Требования

- Android 8.0+ (API 26). Целевое устройство разработки — планшет KENSHI E11 (Android 13).
- Микрофон. Источник аудио `UNPROCESSED` (если устройство его декларирует), иначе `VOICE_RECOGNITION`; шумоподавление и AGC принципиально не включаются.

## Сборка

Kotlin + Jetpack Compose, Gradle KTS, JDK 17, Android SDK 35 (platform 35, build-tools 35.0.0).

```
./gradlew :app:assembleDebug            # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:assembleRelease          # release без минификации, подписан debug-ключом (v0.1 не публикуется)
./gradlew :core-dsp:test                # тесты DSP на синтетике (чистый JVM)
./gradlew :core-dsp:test --tests "*.PitchTest"
./gradlew check                         # тесты + проверка, что JVM-модули не импортируют android.*
```

Модули: `:app` (UI, DI, сессия, сервис, гаптика, настройки), `:core-audio` (AudioRecord, ring buffer, движок), `:core-dsp` (FFT, pitch, метрики, скоринг, калибровка — чистый JVM), `:core-notation` (ноты, октавы, центы — чистый JVM), `:core-testdata` (синтетические сигналы для тестов).

### Цикл «правка → сборка на сервере → планшет»

Рабочая машина разработчика — arm64-VM, под которую AAPT2 не поставляется, поэтому сборка идёт на x86_64-сервере, а установка — на планшет по `adb` в локальной сети:

```
scripts/deploy.sh              # rsync → сервер → assembleDebug → APK в build/ → adb install → запуск
scripts/deploy.sh --test       # только JVM-тесты (:core-dsp, :core-notation) на сервере
scripts/deploy.sh --check      # gradlew check: тесты + защита от android.* в JVM-модулях + lint
scripts/deploy.sh --release    # assembleRelease → build/cupola-release.apk
scripts/deploy.sh --no-install # собрать и скачать APK, не ставить
scripts/deploy.sh --logcat     # после запуска показать logcat приложения
scripts/deploy.sh --test -- --tests "*.PitchTest"   # проброс аргументов Gradle
scripts/tap.sh "Старт"         # тап по элементу UI планшета (для автономных проверок)
scripts/tones.py build/tones   # тестовые тоны для мониторов (aplay build/tones/saw220.wav)
```

Адреса сервера/планшета задаются переменными окружения `CUPOLA_SERVER`, `CUPOLA_SSH_KEY`, `CUPOLA_REMOTE_DIR`, `CUPOLA_DEVICE` (значения по умолчанию — в начале скрипта).

| Цикл (тёплый Gradle-демон) | Время |
|---|---|
| правка → приложение запущено на планшете | ~45–60 с |
| `--test` | ~10–50 с |
| `--check` | ~60 с |
| первый запуск (загрузка Gradle, SDK-компонентов, зависимостей) | ~5 мин |

## Известные ограничения (SPEC §13)

- Все метрики относительные: другой телефон, расстояние или комната — новая калибровка. Числа нельзя сравнивать с другими людьми.
- Певческая форманта формируется месяцами; отсутствие роста за неделю — норма.
- Высокий «звон» можно получить и зажатым звуком; гейты отсекают это лишь частично. Окончательный судья — преподаватель и ощущение свободы горла.
- Твэнг и носовой звук тоже поднимают энергию около 3 кГц; приложение не отличает их надёжно.
- На части устройств `UNPROCESSED` отсутствует, а `VOICE_RECOGNITION` реализован с отклонениями; в настройках есть переключатель источника и индикатор «обработка отключена / не гарантирована».
- Детектор высоты — YIN: на богатых сигналах возможны редкие октавные промахи на один кадр (трек рвётся, а не прыгает). CPPS/HNR и связанные гейты — в следующих версиях.
